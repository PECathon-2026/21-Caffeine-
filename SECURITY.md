# Security

Please don't report security problems in a public issue. Use GitHub's private reporting instead: [report a vulnerability](https://github.com/bas3line/agent-office/security/advisories/new). It reaches [@bas3line](https://github.com/bas3line) directly.

agent office reads your coding agents' transcripts and serves an office on localhost, so reports about anything that leaks prompt text, file contents or secrets onto the page, or that lets another site or another machine reach the office, are especially welcome.

Fixes land on `main` and in the next npm release.
